# Verdant — AI Smart Garden

Intelligent data and real-time tracking to plan, grow, and manage your plants with AI-powered insights.

## Features

- **Live Sensor Monitoring** — Real-time soil moisture, temperature, humidity, and light tracking with animated gauges and sparklines
- **Plant Health Dashboard** — Track individual plants with health scores, growth stages, and care status
- **AI Insights** — Smart recommendations for watering, harvesting, companion planting, and weather alerts
- **Automated Watering Schedule** — AI-driven irrigation plans with zone-based management
- **Garden Zones** — Monitor multiple garden areas with moisture bars and status indicators
- **Growth Analytics** — Visual charts for growth rate, water usage, and yield projections
- **Plant Library** — Searchable database with care guides, difficulty levels, and growing information
- **Dark Mode** — OLED-optimized dark theme with green living accents

## Tech Stack

- Next.js 15 (App Router)
- React 19
- Tailwind CSS 4
- Framer Motion (motion)
- Phosphor Icons
- TypeScript

## Getting Started

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000)

## Deployment

Push to `main` branch to trigger automatic deployment to GitHub Pages.
